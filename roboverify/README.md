# RoboVerify package

Implementation, dependencies and runnable modules live in this directory.
See the [repository README](../README.md) for the documentation index and
[AGENTS.md](../AGENTS.md) for environment setup and module/test commands.

Current primitive defaults use uniform XYZ scaling, 2 mm Pick/Move/Release
stopping tolerances, and fixed-XY Release feedback. Head contacts are disabled
in the active CEE-US Fetch model. Local demonstration archives were deleted;
existing reports and videos are historical artifacts. See the
[controller measurements](synthesis/experiment/CONTROLLER-PATHS.md) for combined
validation and an HTML report. This update does not regenerate demonstrations.
